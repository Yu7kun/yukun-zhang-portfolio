## About｜关于我

我拥有 **媒体传播 + 交互设计** 的跨学科背景：本科就读于 **UNSW Sydney，Public Relations & Advertising**；硕士就读于 **The University of Sydney，Interaction Design and Electronic Arts**。

我的工作通常从一个问题开始：

> **用户是谁？他们为什么这样行动？什么因素真正影响体验与决策？**

我习惯将模糊问题拆成可研究的问题，通过 **文献研究、用户访谈、原型测试、主题分析、竞品/案例研究与内容分析** 建立证据，再把研究发现转化为可以执行的设计、内容或策略方向。

```text
Research → Insight → Strategy → Solution → Test → Iteration
```
